# Прототипы TGCast

Кликабельные прототипы дизайн-задач TGCast. Каждый прототип — статичная сборка фронтенда на моковых данных: бэкенда нет, всё работает прямо в браузере. Данные и каналы выдуманы.

**Открыть:** https://annasova-gaz.github.io/tgcast-prototypes/

## Что внутри

| Папка | Задача | Что смотреть |
|---|---|---|
| [`655-usernames`](./655-usernames/) | TGCASTDEV-655 · Несколько юзернеймов канала | «+N» рядом с юзернеймом и меню остальных юзернеймов: таблица и карточки каталога, быстрый поиск, «Предложить канал», шапка канала |

Подсказка «где смотреть» — в плашке «Прототип» в правом нижнем углу каждого прототипа.

## Как встроить в Notion

В Notion: `/embed` → вставить ссылку на прототип, например
`https://annasova-gaz.github.io/tgcast-prototypes/655-usernames/index.html#/catalog`.
Прототип можно прокликать прямо в странице.

## Как устроено

- Каждая задача — отдельная папка `<номер>-<тема>` со сборкой (`index.html` + `nuxt-assets/`).
- Ссылки внутри прототипа — через `#`, поэтому страницы открываются из подпапки без настройки сервера.
- Корневой `index.html` — оглавление, его обновляют при добавлении прототипа.
- `.nojekyll` нужен GitHub Pages, чтобы отдавать папки, начинающиеся с `_`.
- Поисковики сайт не индексируют (`robots.txt` и `noindex`), но ссылка открыта всем, у кого она есть.

## Обновление

Прототипы собирает Claude из снимка фронтенда TGCast. Новая версия — замена папки задачи и коммит в `main`; GitHub Pages публикует её за 1–2 минуты.

Исходники правок прототипа лежат в рабочей папке проекта: `Valeria world/01_Работа/01_Projects/TG Cast Analytics/Design/prototypes/`.
